# Sambal Empire (web build)

A Malay food-stall tycoon prototype: grow Mak's nasi lemak stall in Kampung Baru into a shop lot and then a franchise.
This repository holds only the playable web build. Best on a phone in landscape; the game text is in everyday spoken Malay
(with an English switch in Settings).

Play: https://syamkushaini.github.io/sambal-empire-web/

On iPhone: open the link in Safari, turn the phone sideways, tap once to start (iOS only allows sound after a tap), then
Share > Add to Home Screen for a full-screen app. Progress is saved in the browser, so clearing Safari data erases it.

Built with Godot 4.7.2. Includes CC0 3D models from Kenney (kenney.nl): Food Kit, Furniture Kit, Nature Kit and City Kit (Suburban).
